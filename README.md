# interactive-kinematics-visualizer
A python project exploring uniformly accelerated motion through calculations, simulation, and graph.
#  Problem Statement
An object moves with constant acceleration. It travels 7 meters during the fifth second of its motion, and the distance traveled during the last second is (1/64) of its total distance. This project aims to determine the object's initial velocity, acceleration, and total time of motion using kinematic equations and Python.
#  Project Goals
Solve the given kinematics problem mathematically;Use Python to calculate and verify the unknown quantities.
# What Does This Project Do?
This project uses kinematic equations and Python calculations to solve a uniformly accelerated motion problem and determine the unknown physical quantities.
# Why Is This Project Useful?
This project demonstrates how mathematical reasoning and basic programming can be combined to solve physics problems and verify calculations.
